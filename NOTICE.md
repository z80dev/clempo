# Third-party data

clempo's code is its own (see the licenses at the repository root). Its tests and its
chain specifications use data recorded or published by others. Every data directory has a
README naming the exact source of each file; this is the summary.

| Data | Source | License of the source |
|---|---|---|
| Mainnet and moderato genesis (`src/tempo/chainspec/data/`), solc storage-layout fixtures | [tempoxyz/tempo](https://github.com/tempoxyz/tempo) | MIT or Apache-2.0 |
| Mainnet and moderato blocks, transactions, receipts, prestates, finalization certificates, DKG outcomes, RPC answers | recorded from the Tempo networks and the reference node | chain data |
| Precompile reference-oracle corpus (`tests/tempo/precompiles/data/oracle.tar.gz`) and other fixtures marked "goempo" | generated by zempo against tempoxyz/tempo, redistributed by [gakonst/goempo](https://github.com/gakonst/goempo) | goempo: MIT or Apache-2.0 |
| Precompile vectors marked "go-ethereum" (bn254, bls12-381, kzg, modexp) | [go-ethereum](https://github.com/ethereum/go-ethereum) `core/vm/testdata/precompiles` | LGPL-3.0 (go-ethereum library); the vectors themselves largely come from the EIPs |
| EIP test vectors (EIP-196/197/198/2537/2565/4844/7883/7951) | the EIPs | CC0-1.0 |
| Wycheproof vectors (P-256, P-384) | [C2SP/wycheproof](https://github.com/C2SP/wycheproof) | Apache-2.0 |
| RFC 6979, RFC 7748, RFC 8032, RFC 8439, RFC 9380 vectors | the RFCs | IETF Trust (code components under BSD-3-Clause) |
| NIST known-answer vectors | NIST CAVP | US Government work |
| KZG trusted-setup point | [c-kzg-4844](https://github.com/ethereum/c-kzg-4844) | Apache-2.0 |
| Commonware wire and signature vectors | [commonwarexyz/monorepo](https://github.com/commonwarexyz/monorepo) | MIT or Apache-2.0 |
| Ethereum trie vectors | [ethereum/tests](https://github.com/ethereum/tests) | MIT |
| Execution-spec-tests fixtures (downloaded at run time, not in the repository) | [ethereum/execution-spec-tests](https://github.com/ethereum/execution-spec-tests) | MIT |

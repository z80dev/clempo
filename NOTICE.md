# Third-party data

clempo's code is its own (see the licenses at the repository root). Its tests and its
chain specifications use data recorded or published by others. The fixture READMEs
document provenance; this file summarizes the licenses of the committed data.

| Data | Source | License of the source |
|---|---|---|
| Mainnet and Moderato genesis (`src/tempo/chainspec/data/`) and [solc storage layouts](tests/tempo/contract/data/layouts/README.md) | [tempoxyz/tempo](https://github.com/tempoxyz/tempo) | MIT or Apache-2.0 |
| Mainnet and moderato blocks, transactions, receipts, prestates, finalization certificates, DKG outcomes, RPC answers | recorded from the Tempo networks and the reference node | chain data |
| Precompile reference-oracle corpus (`tests/tempo/precompiles/data/oracle.tar.gz`) and other fixtures marked "goempo" | generated by zempo against tempoxyz/tempo, redistributed by [gakonst/goempo](https://github.com/gakonst/goempo) | goempo: MIT or Apache-2.0 |
| go-ethereum precompile vectors (listed below) | [go-ethereum](https://github.com/ethereum/go-ethereum/tree/master/core/vm/testdata/precompiles) `core/vm/testdata/precompiles` | [LGPL-3.0](LICENSES/LGPL-3.0.txt), which incorporates [GPL-3.0](LICENSES/GPL-3.0.txt) |

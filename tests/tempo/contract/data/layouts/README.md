# Solidity storage layouts

The 14 `*.layout.json` files are byte-for-byte copies of the [Solidity
storage-layout fixtures in Tempo](https://github.com/tempoxyz/tempo/tree/568b4fb4258c27a08eb193b154f9ca796ce7ff0a/crates/precompiles/tests/storage_tests/solidity/testdata), under Tempo's MIT or Apache-2.0 license. They are solc outputs from the Solidity storage tests in that same upstream directory, not generated by clempo. Local layout tests compare the slots, packing and storage types emitted by `clempo.contract` with those fixtures.
